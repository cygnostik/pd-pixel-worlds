# Artwork and names

The bundled scenes and sprites are original procedural Canvas artwork. This
repository includes no film stills, extracted game assets, commercial sprite
sheets, franchise audio, supplied reference images or third-party design handbooks.

Office Space is a film-inspired demonstration. Star Trek: The Next Generation
is an unofficial fan-inspired bridge demonstration. Their names, characters,
marks and underlying properties belong to their respective owners. Neither demo
is affiliated with or endorsed by those owners. The MIT license covers our code
and original contributions; it does not grant rights to third-party properties
or trademarks. Kitten Café is an original setting.

React and React DOM are MIT-licensed; their license notices remain in the bundled
browser preview. Hermes Desktop supplies React and its plugin SDK to the installed
plugin. The preview SDK shim is a local test fixture, not redistributed Hermes code.

Community realms must declare the rights and licenses for every included asset.
Submit original work or assets you have permission to distribute.
